# Rock Paper Scissors

A simple command-line Rock, Paper, Scissors game written in Python. Play against the computer and see who wins each round!

## Features

- Play against a computer opponent that picks randomly
- Input validation for invalid choices
- Play as many rounds as you like, then type `quit` to exit

## Requirements

- Python 3.6 or higher

No external libraries needed.

## How to Run

1. Clone this repository:
   ```
   git clone https://github.com/amcki/rock-paper-scissors.git
   ```
2. Navigate into the project folder:
   ```
   cd rock-paper-scissors
   ```
3. Run the game:
   ```
   python rps.py
   ```
   (On Mac/Linux you may need to use `python3 rps.py`)

## How to Play

1. Type `rock`, `paper`, or `scissors` when prompted.
2. The computer makes its choice and the winner is shown.
3. Type `quit` at any time to stop playing.

## Example

```
Choose rock, paper, or scissors (or 'quit' to exit): rock
Computer chose: scissors
You win!
```

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
